# @voidhash/react-native

## 0.1.1

### Patch Changes

- Android builds no longer fail with "defined multiple times" errors, such as for `RNCSafeAreaProviderManagerDelegate`, when the package manager installs copies of other React Native libraries inside the SDK's own `node_modules`. The SDK no longer runs React Native's codegen on Android: its native module is generated by Nitro, so codegen had nothing of its own to build and picked up those copies instead.
- On Android, a pressable part of a flow's text reaches TalkBack as a link rather than a button: TalkBack says "link" in the reader's language and lists it among the screen's links, and choosing it there or double-tapping it presses it.
- Flows tell VoiceOver and TalkBack what each layer is: a layer can carry an accessibility label (translated per language), a role (button, link, header or image), or be hidden from screen readers, and each pressable part of a text is reachable on its own. A pushed screen also settles faster when drawn outside the built-in renderer.
- Present flows made for a location: pass the location's inputs, answer the app actions a flow calls, and read back its outputs and the outcome it ended with, including lists. A flow's text inputs take the system keyboard, move focus from field to field on their own, and work with VoiceOver and TalkBack, which also read the layers a flow describes for them. A flow ends as its purchase or restore says, and runs on the runtime its release names. The native iOS and Android SDKs share these changes.
- Updated dependencies
  - @voidhash/android@0.1.1
  - @voidhash/ios@0.1.1
