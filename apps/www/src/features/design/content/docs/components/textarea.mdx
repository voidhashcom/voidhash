title: Textarea
description: A multi-line text input for longer form content.
---

## Usage

<Preview centered={false}>
  <Textarea placeholder="Type your message here..." className="w-full max-w-md" />
</Preview>

```tsx
import { Textarea } from "@voidhash/ui";

<Textarea placeholder="Type your message here..." />;
```

## Examples

  </div>

```tsx
<div className="grid gap-2">
```
