---
title: Badge
description: Displays a small label or indicator for status, categories, or counts.
---

## Usage

<Preview>
  <Badge>Badge</Badge>
</Preview>

```tsx
import { Badge } from "@voidhash/ui";

<Badge>Badge</Badge>;
```

### With Icon

### As Link

Use the `asChild` prop to render the badge as a link:

<Preview>
  <Badge asChild>
    <a href="#">Clickable Badge</a>
  </Badge>
</Preview>

```tsx
<Badge asChild>
  <a href="/category">Category</a>
</Badge>
```
