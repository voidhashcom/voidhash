## Usage

<Preview centered={false}>
  <Alert>
    <AlertCircleIcon />
    <AlertTitle>Heads up!</AlertTitle>
    <AlertDescription>You can add components to your app using the CLI.</AlertDescription>
  </Alert>
</Preview>

```tsx
import { Alert, AlertDescription, AlertTitle } from "@voidhash/ui";
import { AlertCircleIcon } from "lucide-react";

<Alert>
  <AlertCircleIcon />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>You can add components to your app using the CLI.</AlertDescription>
</Alert>;
```

## Components

### Alert

The main container component with variant styling.

### AlertTitle

The title of the alert message.

### AlertDescription

The description or body text of the alert.
