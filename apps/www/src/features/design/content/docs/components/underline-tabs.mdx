## Usage

<Preview centered={false}>
  <UnderlineTabs defaultValue="account" className="w-full max-w-md">
    <UnderlineTabsList>
      <UnderlineTabsTrigger value="account">Account</UnderlineTabsTrigger>
      <UnderlineTabsTrigger value="password">Password</UnderlineTabsTrigger>
      <UnderlineTabsTrigger value="settings">Settings</UnderlineTabsTrigger>
    </UnderlineTabsList>
    <UnderlineTabsContent value="account" className="pt-4">
      <p>Account settings content.</p>
    </UnderlineTabsContent>
    <UnderlineTabsContent value="password" className="pt-4">
      <p>Password settings content.</p>
    </UnderlineTabsContent>
    <UnderlineTabsContent value="settings" className="pt-4">
      <p>Other settings content.</p>
    </UnderlineTabsContent>
  </UnderlineTabs>
</Preview>

```tsx
import {
  UnderlineTabs,
  UnderlineTabsContent,
  UnderlineTabsList,
  UnderlineTabsTrigger,
} from "@voidhash/ui";

<UnderlineTabs defaultValue="account">
  <UnderlineTabsList>
    <UnderlineTabsTrigger value="account">Account</UnderlineTabsTrigger>
    <UnderlineTabsTrigger value="password">Password</UnderlineTabsTrigger>
  </UnderlineTabsList>
  <UnderlineTabsContent value="account">Account content</UnderlineTabsContent>
  <UnderlineTabsContent value="password">Password content</UnderlineTabsContent>
</UnderlineTabs>;
```

## Components

### UnderlineTabs

The root container managing tab state.

### UnderlineTabsList

The container for tab triggers with underline styling.

### UnderlineTabsTrigger

A tab button with underline indicator.

### UnderlineTabsContent

The content panel for each tab.

## Comparison with Tabs

The UnderlineTabs component uses an underline indicator style, while the regular Tabs component uses a pill/segment style. Choose based on your design needs:

- **UnderlineTabs**: Minimal, underline indicator, good for content sections
- **Tabs**: Pill/segment style, good for switching between views
