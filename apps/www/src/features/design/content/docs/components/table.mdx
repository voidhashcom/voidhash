## Components

### Table

The root table container with horizontal scroll support.

### TableHeader

The table header section containing column headers.

### TableBody

The table body section containing data rows.

### TableFooter

The table footer section for summary data.

### TableRow

A single row in the table.

### TableHead

A header cell in the table.

### TableCell

A data cell in the table.

### TableCaption

An optional caption describing the table.
