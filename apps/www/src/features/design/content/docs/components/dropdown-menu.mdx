---
title: Dropdown Menu
description: A menu with a set of actions triggered by a button.
---

## Usage

<Preview>
  <DropdownMenu>
    <DropdownMenuTrigger asChild>
      <Button variant="outline">Open Menu</Button>
    </DropdownMenuTrigger>
    <DropdownMenuContent>
      <DropdownMenuLabel>My Account</DropdownMenuLabel>
      <DropdownMenuSeparator />
      <DropdownMenuItem>
        <UserIcon /> Profile
      </DropdownMenuItem>
      <DropdownMenuItem>
        <SettingsIcon /> Settings
      </DropdownMenuItem>
      <DropdownMenuSeparator />
      <DropdownMenuItem variant="destructive">
        <TrashIcon /> Delete
      </DropdownMenuItem>
    </DropdownMenuContent>
  </DropdownMenu>
</Preview>

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@voidhash/ui";

<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button variant="outline">Open Menu</Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuLabel>My Account</DropdownMenuLabel>
    <DropdownMenuSeparator />
    <DropdownMenuItem>Profile</DropdownMenuItem>
    <DropdownMenuItem>Settings</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>;
```

## Components

### DropdownMenu

The root component managing menu state.

### DropdownMenuTrigger

The element that opens the menu.

### DropdownMenuContent

The popup content container.

### DropdownMenuItem

A clickable menu item.

### DropdownMenuLabel

A non-interactive label.

### DropdownMenuSeparator

A visual divider between items.

### DropdownMenuCheckboxItem

A menu item with a checkbox.

### DropdownMenuRadioGroup / DropdownMenuRadioItem

Radio button items for single selection.

### DropdownMenuShortcut

Displays keyboard shortcut text.

### DropdownMenuSub / DropdownMenuSubTrigger / DropdownMenuSubContent

Nested submenu components.
