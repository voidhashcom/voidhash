## Usage

<Preview>
  <InputOTP maxLength={6}>
    <InputOTPGroup>
      <InputOTPSlot index={0} />
      <InputOTPSlot index={1} />
      <InputOTPSlot index={2} />

```tsx
import { InputOTP, InputOTPGroup, InputOTPSeparator, InputOTPSlot } from "@voidhash/ui";

<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>;
```

## Components

### InputOTP

The root component managing OTP input state.

### InputOTPGroup

A group of OTP slots.

### InputOTPSlot

A single input slot for one character.

### InputOTPSeparator

A visual separator between groups.

### Controlled

```tsx
const [value, setValue] = useState("");

<InputOTP maxLength={6} value={value} onChange={setValue}>
  ...
</InputOTP>;
```

### Pattern Validation

```tsx
<InputOTP maxLength={6} pattern={REGEXP_ONLY_DIGITS}>
  ...
</InputOTP>
```
