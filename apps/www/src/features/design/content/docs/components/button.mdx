---
title: Button
description: A versatile button component with multiple variants and sizes.
---

## Usage

<Preview>
  <Button>Click me</Button>
</Preview>

```tsx
import { Button } from "@voidhash/ui";

<Button>Click me</Button>;
```

## Variants

The Button component supports the following visual variants:

## Examples

### With Icon

<Preview>
  <Button>
    <MailIcon /> Login with Email
  </Button>
</Preview>

```tsx
<Button>
  <MailIcon /> Login with Email
</Button>
```

### Disabled State

<Preview>
  <Button disabled>Disabled</Button>
</Preview>

```tsx
<Button disabled>Disabled</Button>
```

### Loading State

Use the `loading` prop to show a spinner and disable the button:

<Preview>
  <Button loading>Loading</Button>
</Preview>

```tsx
<Button loading>Loading</Button>
```

<div className="flex flex-wrap items-center gap-4">
  <Preview className="p-4">
    <Button loading>Saving...</Button>
  </Preview>
  <Preview className="p-4">
    <Button variant="secondary" loading>
      Processing
    </Button>
  </Preview>
  <Preview className="p-4">
    <Button variant="outline" loading>
      Loading
    </Button>
  </Preview>
</div>

```tsx
<Button loading>Saving...</Button>
<Button variant="secondary" loading>Processing</Button>
<Button variant="outline" loading>Loading</Button>
```

### As Link

Use the `asChild` prop to render the button as a child element, like a link:

<Preview>
  <Button asChild>
    <a href="#">Link Button</a>
  </Button>
</Preview>

```tsx
<Button asChild>
  <a href="/dashboard">Go to Dashboard</a>
</Button>
```
