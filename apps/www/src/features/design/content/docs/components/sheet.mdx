## Usage

<Preview>
  <Sheet>
    <SheetTrigger asChild>
      <Button variant="outline">Open Sheet</Button>
    </SheetTrigger>
    <SheetContent>
      <SheetHeader>
        <SheetTitle>Sheet Title</SheetTitle>
        <SheetDescription>
          This is a sheet description. Make changes to your settings here.
        </SheetDescription>
      </SheetHeader>
      <div className="p-4">
        <p>Sheet content goes here.</p>
      </div>
      <SheetFooter>
        <Button>Save changes</Button>
      </SheetFooter>
    </SheetContent>
  </Sheet>
</Preview>

```tsx
import {
  Sheet,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@voidhash/ui";

<Sheet>
  <SheetTrigger asChild>
    <Button variant="outline">Open Sheet</Button>
  </SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Sheet Title</SheetTitle>
      <SheetDescription>Sheet description.</SheetDescription>
    </SheetHeader>
    <div className="p-4">Content here</div>
    <SheetFooter>
      <Button>Save</Button>
    </SheetFooter>
  </SheetContent>
</Sheet>;
```

## Components

### Sheet

The root component managing sheet state.

### SheetTrigger

The element that opens the sheet.

### SheetContent

The sliding panel content.

### SheetHeader

Container for title and description.

### SheetTitle

The sheet's heading.

### SheetDescription

A description of the sheet's purpose.

### SheetFooter

Container for action buttons.

### SheetClose

An element that closes the sheet.
