---
title: Tooltip
description: A popup that displays information related to an element when focused or hovered.
---

## Usage

<Preview>
  <Tooltip>
    <TooltipTrigger render={<Button variant="outline">Hover me</Button>} />
    <TooltipPopup>
      <p>This is a tooltip</p>
    </TooltipPopup>
  </Tooltip>
</Preview>

```tsx
import { Tooltip, TooltipPopup, TooltipTrigger } from "@voidhash/ui";

<Tooltip>
  <TooltipTrigger render={<Button variant="outline">Hover me</Button>} />
  <TooltipPopup>
    <p>This is a tooltip</p>
  </TooltipPopup>
</Tooltip>;
```

## Components

### Tooltip

The root component that wraps the trigger and popup. Automatically provides a
`TooltipProvider` with a zero open delay, so isolated tooltips work without any
extra setup.

### TooltipTrigger

The element that triggers the tooltip on hover/focus. Pass the rendered element
via the `render` prop, or use the legacy `asChild` pattern for backwards
compatibility.

### TooltipPopup

The popup content displayed when triggered. Internally renders a Base UI
`Portal`, `Positioner`, `Popup`, and `Viewport`. `TooltipContent` is exported as
an alias for backwards compatibility.

### TooltipProvider

Provides shared delay / grouping behavior for nested tooltips. Mount this once
near the root of the app (or sidebar) when many tooltips should share a single
delay timer.

### IconButtonTooltip

Convenience wrapper for the common pattern of tooltipping an icon button.
