## Usage

<Preview centered={false}>
  <ScrollArea className="h-72 w-48 rounded-md border">
    <div className="p-4">
      <h4 className="mb-4 text-sm font-medium leading-none">Tags</h4>
      {Array.from({ length: 50 }).map((_, i) => (
        <div key={i} className="text-sm py-1">
          Tag {i + 1}
        </div>
      ))}
    </div>
  </ScrollArea>
</Preview>

```tsx
import { ScrollArea } from "@voidhash/ui";

<ScrollArea className="h-72 w-48 rounded-md border">
  <div className="p-4">{/* Long content here */}</div>
</ScrollArea>;
```

## Components

### ScrollArea

The main scrollable container with custom scrollbars.

### ScrollBar

The scrollbar track and thumb, customizable for horizontal or vertical.

## Examples

### Horizontal Scroll

<Preview centered={false}>
  <ScrollArea className="w-96 whitespace-nowrap rounded-md border">
    <div className="flex w-max space-x-4 p-4">
      {Array.from({ length: 20 }).map((_, i) => (
        <div key={i} className="w-32 h-24 rounded-md bg-muted flex items-center justify-center">
          Item {i + 1}
        </div>
      ))}
    </div>
    <ScrollBar orientation="horizontal" />
  </ScrollArea>
</Preview>

```tsx
<ScrollArea className="w-96 whitespace-nowrap rounded-md border">
  <div className="flex w-max space-x-4 p-4">{/* Horizontal content */}</div>
  <ScrollBar orientation="horizontal" />
</ScrollArea>
```
