```tsx
import {
  Menubar,
  MenubarCheckboxItem,
  MenubarContent,
  MenubarItem,
  MenubarMenu,
  MenubarSeparator,
  MenubarShortcut,
  MenubarTrigger,
} from "@voidhash/ui";

<Menubar>
  <MenubarMenu>
    <MenubarTrigger>File</MenubarTrigger>
    <MenubarContent>
      <MenubarItem>New Tab</MenubarItem>
      <MenubarItem>New Window</MenubarItem>
    </MenubarContent>
  </MenubarMenu>
</Menubar>;
```

## Components

### Menubar

The root horizontal menu container.

### MenubarMenu

A single menu in the menubar.

### MenubarTrigger

The trigger button for a menu.

### MenubarContent

The dropdown content of a menu.

### MenubarItem

A clickable menu item.

### MenubarCheckboxItem

A menu item with a checkbox.

### MenubarRadioGroup / MenubarRadioItem

Radio button items.

### MenubarLabel

A non-interactive label.

### MenubarSeparator

A visual divider.

### MenubarShortcut

Displays keyboard shortcut text.

### MenubarSub / MenubarSubTrigger / MenubarSubContent

Submenu components.
