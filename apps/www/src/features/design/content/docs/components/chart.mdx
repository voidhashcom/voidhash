## Usage

The Chart components provide a styled wrapper around Recharts library.

```tsx
import {
  ChartContainer,
  ChartTooltip,
  ChartTooltipContent,
  ChartLegend,
  ChartLegendContent,
} from "@voidhash/ui";
import { Bar, BarChart, XAxis, YAxis } from "recharts";

const chartConfig = {
  desktop: {
    label: "Desktop",
    color: "hsl(var(--chart-1))",
  },
  mobile: {
    label: "Mobile",
    color: "hsl(var(--chart-2))",
  },
};

const data = [
  { month: "January", desktop: 186, mobile: 80 },
  { month: "February", desktop: 305, mobile: 200 },
  { month: "March", desktop: 237, mobile: 120 },
];

<ChartContainer config={chartConfig} className="h-[300px]">
  <BarChart data={data}>
    <XAxis dataKey="month" />
    <YAxis />
    <ChartTooltip content={<ChartTooltipContent />} />
    <ChartLegend content={<ChartLegendContent />} />
    <Bar dataKey="desktop" fill="var(--color-desktop)" />
    <Bar dataKey="mobile" fill="var(--color-mobile)" />
  </BarChart>
</ChartContainer>;
```

## Components

### ChartContainer

The main wrapper that provides chart configuration and styling.

### ChartTooltip

A styled tooltip for displaying data on hover.

### ChartTooltipContent

The content rendered inside the tooltip.

### ChartLegend

A legend component for the chart.

### ChartLegendContent

The content rendered inside the legend.

## Configuration

Define a chart config object to map data keys to labels and colors:

```tsx
const chartConfig = {
  revenue: {
    label: "Revenue",
    color: "hsl(var(--chart-1))",
  },
  expenses: {
    label: "Expenses",
    color: "hsl(var(--chart-2))",
  },
};
```

## Available Chart Types

You can use any Recharts chart type:

- AreaChart
- BarChart
- LineChart
- PieChart
- RadarChart
- RadialBarChart
