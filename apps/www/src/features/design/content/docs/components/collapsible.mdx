## Usage

<Preview centered={false}>
  <Collapsible className="w-full max-w-md space-y-2">

```tsx
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@voidhash/ui";

<Collapsible>
  <div className="flex items-center justify-between">
    <span>Toggle content</span>
    <CollapsibleTrigger asChild>
      <Button variant="ghost" size="sm">
        <ChevronDownIcon />
      </Button>
    </CollapsibleTrigger>
  </div>
  <CollapsibleContent>Hidden content here</CollapsibleContent>
</Collapsible>;
```

## Components

### Collapsible

The root component managing collapse state.

### CollapsibleTrigger

The element that toggles the collapsed state.

### CollapsibleContent

The content that is shown/hidden.

## Examples

### Controlled

```tsx
const [isOpen, setIsOpen] = useState(false);

<Collapsible open={isOpen} onOpenChange={setIsOpen}>
  <CollapsibleTrigger>Toggle</CollapsibleTrigger>
  <CollapsibleContent>Content</CollapsibleContent>
</Collapsible>;
```
