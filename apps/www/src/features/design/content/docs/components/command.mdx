## Components

### Command

The root command palette container.

### CommandInput

The search input field.

### CommandList

The scrollable list of results.

### CommandEmpty

Message shown when no results match.

### CommandGroup

A group of related items with a heading.

### CommandItem

An individual selectable item.

### CommandSeparator

A visual divider between groups.

### CommandShortcut

Displays keyboard shortcut text.

### CommandDialog

A dialog-wrapped command palette.

## Examples

### Command Dialog

<Preview>
  <Button variant="outline" className="text-muted-foreground">
    <SearchIcon className="mr-2 h-4 w-4" />
    <span>Search...</span>
    <CommandShortcut className="ml-4">⌘K</CommandShortcut>
  </Button>
</Preview>

```tsx
import { CommandDialog } from "@voidhash/ui";

const [open, setOpen] = useState(false);

<CommandDialog open={open} onOpenChange={setOpen}>
  <CommandInput placeholder="Search..." />
  <CommandList>
    <CommandEmpty>No results found.</CommandEmpty>
    <CommandGroup heading="Actions">
      <CommandItem>New File</CommandItem>
      <CommandItem>New Folder</CommandItem>
    </CommandGroup>
  </CommandList>
</CommandDialog>;
```

### With Keyboard Shortcut

```tsx
useEffect(() => {
  const down = (e: KeyboardEvent) => {
    if (e.key === "k" && (e.metaKey || e.ctrlKey)) {
      e.preventDefault();
      setOpen((open) => !open);
    }
  };
  document.addEventListener("keydown", down);
  return () => document.removeEventListener("keydown", down);
}, []);
```
