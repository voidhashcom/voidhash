---
title: Drawer
description: A touch-friendly panel that slides from any edge with gesture support.
---

## Usage

<Preview>
  <Drawer>
    <DrawerTrigger asChild>
      <Button variant="outline">Open Drawer</Button>
    </DrawerTrigger>
    <DrawerContent>
      <DrawerHeader>
        <DrawerTitle>Drawer Title</DrawerTitle>
        <DrawerDescription>This is a drawer with touch gestures support.</DrawerDescription>
      </DrawerHeader>
      <div className="p-4">
        <p>Drawer content goes here.</p>
      </div>
      <DrawerFooter>
        <Button>Submit</Button>
        <DrawerClose asChild>
          <Button variant="outline">Cancel</Button>
        </DrawerClose>
      </DrawerFooter>
    </DrawerContent>
  </Drawer>
</Preview>

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@voidhash/ui";

<Drawer>
  <DrawerTrigger asChild>
    <Button variant="outline">Open Drawer</Button>
  </DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Drawer Title</DrawerTitle>
      <DrawerDescription>Description here.</DrawerDescription>
    </DrawerHeader>
    <div className="p-4">Content</div>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose asChild>
        <Button variant="outline">Cancel</Button>
      </DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>;
```

## Components

### Drawer

The root component managing drawer state.

### DrawerTrigger

The element that opens the drawer.

### DrawerContent

The sliding panel with a handle indicator.

### DrawerHeader

Container for title and description.

### DrawerTitle

The drawer's heading.

### DrawerDescription

A description of the drawer's purpose.

### DrawerFooter

Container for action buttons.

### DrawerClose

An element that closes the drawer.
