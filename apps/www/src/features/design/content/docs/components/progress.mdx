---
title: Progress
description: Displays an indicator showing the completion progress of a task.
---

## Usage

<Preview centered={false}>
  <Progress value={33} className="w-full max-w-md" />
</Preview>

```tsx
import { Progress } from "@voidhash/ui";

<Progress value={33} />;
```
