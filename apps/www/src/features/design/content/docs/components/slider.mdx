---
title: Slider
description: An input component for selecting a value from a range.
---

## Usage

<Preview centered={false}>
  <Slider defaultValue={[50]} max={100} step={1} className="w-full max-w-md" />
</Preview>

```tsx
import { Slider } from "@voidhash/ui";

<Slider defaultValue={[50]} max={100} step={1} />;
```

## Examples

### Range Slider

<Preview centered={false}>
