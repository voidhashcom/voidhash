---
title: Avatar
description: An image element with a fallback for representing the user.
---

## Usage

<Preview>
  <Avatar>
    <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
    <AvatarFallback>CN</AvatarFallback>
  </Avatar>
</Preview>

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@voidhash/ui";

<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>;
```

## Components

### Avatar

The root container that wraps the image and fallback.

### AvatarImage

The image element that displays the user's avatar.

### AvatarFallback

A fallback element shown when the image fails to load.
