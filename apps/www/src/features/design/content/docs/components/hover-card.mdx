## Usage

<Preview>
  <HoverCard>
    <HoverCardTrigger asChild>
      <Button variant="link">@nextjs</Button>
    </HoverCardTrigger>
    <HoverCardContent>
      <div className="flex justify-between space-x-4">
        <Avatar>
          <AvatarImage src="https://github.com/vercel.png" />

          <div className="flex items-center pt-2">

          </div>
        </div>
      </div>
    </HoverCardContent>
  </HoverCard>

```tsx
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@voidhash/ui";

<HoverCard>
  <HoverCardTrigger asChild>
    <Button variant="link">@nextjs</Button>
  </HoverCardTrigger>
  <HoverCardContent>
    <div className="space-y-1">
      <h4 className="text-sm font-semibold">@nextjs</h4>
      <p className="text-sm">The React Framework.</p>
    </div>
  </HoverCardContent>
</HoverCard>;
```

## Components

### HoverCard

The root component managing hover state.

### HoverCardTrigger

The element that triggers the card on hover.

### HoverCardContent

The popup card content.
