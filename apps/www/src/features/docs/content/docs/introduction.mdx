Voidhash is an in-app purchases and subscription management platform designed for **React Native**. Implementing in-app purchases has always been about as enjoyable as debugging production code at 3 AM. With Voidhash, you get server-side receipt validation, CRM, analytics, and more in under 5 minutes. Built by developers who've felt your pain. And the best part? It's Open Source.

## Features

- Google Play and App Store support
- Server-side receipt validation
- Person Management
- Analytics
- Powerful CLI
