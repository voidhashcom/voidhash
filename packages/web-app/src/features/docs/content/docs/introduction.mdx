Voidhash connects your React Native app to the App Store and Google Play. Use it to build paywalls,
validate purchases, keep subscription state in sync, and decide what each customer can access.

## How it fits together

| Part                 | What it does                                                                      |
| -------------------- | --------------------------------------------------------------------------------- |
| **Studio**           | Configure products and perks, design paywalls, and review customers and revenue.  |
| **React Native SDK** | Display paywalls, make and restore purchases, and read access state in your app.  |
| **Voidhash backend** | Validate store transactions and keep subscriptions and entitlements current.      |
| **CLI**              | Connect a local project, generate typed slugs, and deploy code-authored paywalls. |

Your app ships only a **publishable key** (`vh_pk_...`). Store credentials and secret keys stay on
the server.

## Start here

The [React Native quickstart](/quickstart) is the shortest path from an existing app to a working
paywall and entitlement check.

Before you start, you need:

- an Expo development build or a bare React Native app;
- a Voidhash project and its publishable key;
- an App Store or Google Play subscription product; and
- a deep-link scheme for your app.

<Callout type="warn" title="Expo Go is not supported">
  The SDK includes native StoreKit and Google Play Billing modules. Use an Expo development build or
  a bare React Native app.
</Callout>
