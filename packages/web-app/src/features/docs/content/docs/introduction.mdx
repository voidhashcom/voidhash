Voidhash connects your app to the App Store and Google Play. Use it to build paywalls, validate
purchases, keep subscription state in sync, and decide what each customer can access.

## How it fits together

| Part                 | What it does                                                                      |
| -------------------- | --------------------------------------------------------------------------------- |
| **Studio**           | Configure products and perks, design paywalls, and review customers and revenue.  |
| **Mobile SDKs**      | Display paywalls, make and restore purchases, and read access state in your app.  |
| **Voidhash backend** | Validate store transactions and keep subscriptions and entitlements current.      |
| **CLI**              | Connect a local project, generate typed slugs, and deploy code-authored paywalls. |

Your app ships only a **publishable key** (`vh_pk_...`). Store credentials and secret keys stay on
the server.

## Pick your SDK

Voidhash ships three client SDKs with the same core workflows — paywalls, purchases,
entitlements, feature flags, and analytics — tailored to each platform:

- [**React Native**](/sdks/react-native) — Expo development builds and bare React Native apps on
  iOS and Android.
- [**Swift**](/sdks/swift) — native iOS apps on StoreKit 2 (iOS 15+).
- [**Kotlin**](/sdks/kotlin) — native Android apps on Google Play Billing (minSdk 23).

The [quickstart](/quickstart) is the shortest path from an existing app to a working paywall and
entitlement check.
