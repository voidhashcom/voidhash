title: API overview

---

Use the HTTP API for server integrations and custom tooling. Mobile apps should use the
[React Native SDK](/react-native), which handles device headers, identity, caching, and store
transactions.

## Base URL

```text
https://api.voidhash.com
```

Management endpoints live under `/api/v1`. Analytics ingestion uses the separate `/i/v1` surface.

## First request

Create a project secret key in Studio and inspect its session:

```bash
curl https://api.voidhash.com/api/v1/auth/session \
  -H "x-secret-key: $VOIDHASH_SECRET_KEY"
```

Keep secret keys on the server. See [Authentication](/api/authentication) for every credential
type.

## Endpoint groups

| Group              | Use                                                                     |
| ------------------ | ----------------------------------------------------------------------- |
| API keys           | Create and rotate project credentials.                                  |
| Persons            | Create and look up customer records.                                    |
| Products and perks | Read the project catalog and product-to-perk relationships.             |
| Paywall locations  | Read the locations available to clients.                                |
| Schema             | Fetch the consolidated project schema and version.                      |
| Webhooks           | Manage endpoints, inspect deliveries, rotate secrets, and retry events. |
| Paywall deploys    | Upload and finalize code-authored paywalls.                             |
| SDK                | Device-facing endpoints used by official SDKs.                          |

The generated endpoint pages contain request schemas, response schemas, and an interactive client.

## Errors

Management API errors are JSON objects with a stable `_tag`:

```json
{
  "_tag": "Api/NotAuthenticatedError",
  "message": "You are not authenticated"
}
```

Use the HTTP status for the broad outcome and `_tag` for application behavior. Do not parse the
human-readable message.

| Status | Meaning                                           |
| ------ | ------------------------------------------------- |
| `400`  | Invalid request or parameters.                    |
| `401`  | Missing or invalid credentials.                   |
| `403`  | Credential does not permit the action.            |
| `404`  | Resource not found.                               |
| `409`  | Request conflicts with current state.             |
| `429`  | Rate limited. Retry after the indicated delay.    |
| `5xx`  | Server failure. Retry safe requests with backoff. |

## OpenAPI

Machine-readable specifications are available at:

- `GET /api/docs/openapi.json` for the management and SDK API;
- `GET /i/docs/openapi.json` for event capture.
