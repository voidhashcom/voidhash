---
title: Create a Google Play service account key
description: Create and download the JSON key used to validate Google Play purchases.
---

Voidhash needs a **service account JSON key** with access to your app in Google Play Console.

<Steps>

<Step>
### Enable the Google Play API

In [Google Cloud Console](https://console.cloud.google.com), select or create a project.
Open **APIs & Services → Library**, find **Google Play Android Developer API**, and enable it.

</Step>

<Step>
### Create or select a service account

Open **IAM & Admin → Service Accounts** in the same project. Select an existing account or
choose **Create service account**. Copy its email address.

</Step>

<Step>
### Grant access in Play Console

In [Google Play Console](https://play.google.com/console), open **Users and permissions →
Invite new users**. Enter the service account email and grant access to your app with:

- **View financial data, orders, and cancellation survey responses**
- **Manage orders and subscriptions**

Save the invitation. Google's [Developer API setup](https://developers.google.com/android-publisher/getting_started#use_a_service_account)
explains the required access.

</Step>

<Step>
### Download the JSON key

Back in Google Cloud, open the service account, select **Keys → Add key → Create new key**,
choose **JSON**, and click **Create**. Your browser downloads the key file.

If key creation is unavailable, ask your Cloud administrator to check your permissions and
the project's organization policy. See Google's [key creation guide](https://cloud.google.com/iam/docs/keys-create-delete).

</Step>

<Step>
### Upload it to Voidhash

Attach the downloaded `.json` file to **Service account key file** and save the provider.
Upload the whole file, rather than an individual key ID or a Firebase `google-services.json` file.

<Callout type="warn" title="Keep the downloaded key private">
  The file contains a private key. Store it securely and keep it out of your app and source control.
  Google only offers the download when the key is created. If you lose the file, create a
  replacement.
</Callout>

</Step>

</Steps>
