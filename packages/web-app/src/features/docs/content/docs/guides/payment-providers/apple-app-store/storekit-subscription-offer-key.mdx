---
title: Find your StoreKit subscription offer key
description: Export the private key used to sign subscription offers in your StoreKit test setup.
---

This optional field is for apps that test subscription offers with an Xcode StoreKit configuration.
It is not required for a basic subscription purchase flow.

<Steps>

<Step>
### Open the StoreKit configuration

In Xcode, select the `.storekit` configuration used by the current scheme. Create one from
**File → New → File → StoreKit Configuration File** if the project does not have one.

</Step>

<Step>
### Export the offer key

With the StoreKit file selected, use Xcode's **Editor → Subscription Offers Key** action. Export or
save the private key as a `.p8` file.

Xcode labels can change between releases; use the subscription-offer key attached to this StoreKit
configuration, not a production key copied from another app.

</Step>

<Step>
### Upload the file

Upload the `.p8` file to **StoreKit Subscription Offer key** in Voidhash and save the provider.

</Step>

</Steps>
