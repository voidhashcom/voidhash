---
title: Find App Store Connect API values
description: Locate the Issuer ID, Key ID, and Vendor Number requested by Voidhash.
---

<Steps>

<Step>
### Open Team Keys

In [App Store Connect](https://appstoreconnect.apple.com), open **Users and Access**, choose
**Integrations**, then open **App Store Connect API → Team Keys**.

The Account Holder must enable API access before an Account Holder or Admin can generate team keys.

</Step>

<Step>
### Copy the Issuer ID

Copy the team-wide **Issuer ID** shown above the active keys table and paste it into Voidhash.

</Step>

<Step>
### Copy the Key ID

Generate or select the Team Key used for product metadata access. Copy its **Key ID** into
Voidhash. If you generate a new key, securely store its one-time `.p8` download with your team's
credentials.

</Step>

<Step>
### Find the Vendor Number

Open **Payments and Financial Reports**, choose **Reports**, and copy the **Vendor Number** shown for
the legal entity that owns this app. Paste it into Voidhash.

</Step>

</Steps>
