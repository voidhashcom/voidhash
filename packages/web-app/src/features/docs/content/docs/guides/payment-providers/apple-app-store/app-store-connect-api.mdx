---
title: Find App Store Connect API values
description: Find the Issuer ID, Key ID, and Vendor Number that Voidhash asks for.
---

Voidhash uses an App Store Connect API team key to read product metadata for your app. You collect
three values from App Store Connect: the **Issuer ID**, the **Key ID**, and your **Vendor Number**.

<Steps>

<Step>
### Open Team Keys

In [App Store Connect](https://appstoreconnect.apple.com), open **Users and Access**, choose
**Integrations**, then open **App Store Connect API → Team Keys**.

The Account Holder must enable API access first. After that, an Account Holder or Admin can
generate team keys.

</Step>

<Step>
### Copy the Issuer ID

The team-wide **Issuer ID** is shown above the active keys table. Copy it and paste it into
Voidhash.

</Step>

<Step>
### Copy the Key ID

Generate or select the Team Key that Voidhash will use for product metadata access, then copy its
**Key ID** into Voidhash.

If you generate a new key, Apple offers its `.p8` file for download only once. Store that download
securely with your team's credentials.

</Step>

<Step>
### Find the Vendor Number

Open **Payments and Financial Reports** and choose **Reports**. Copy the **Vendor Number** shown
for the legal entity that owns this app, and paste it into Voidhash.

</Step>

</Steps>
