---
title: Configure Apple Server Notifications
description: Point App Store Server Notifications V2 at Voidhash so renewals, cancellations, and refunds are processed automatically.
---

**App Store Server Notifications** let Apple push subscription events straight to Voidhash. That
includes purchases, renewals, cancellations, and refunds. Unlike the other App Store values, you do
not copy anything out of App Store Connect here. Instead, you paste the URL that Voidhash provides
into Apple's notification settings and select Version 2.

<Steps>

<Step>
### Copy your Voidhash notification URL

In Voidhash, open the **Apple Server notification** tab of this payment provider. Copy the
**Apple Server Notification URL** using the copy button next to it.

The URL is a publicly reachable HTTPS endpoint. Your server must support TLS 1.2 or later for
Apple to deliver notifications.

</Step>

<Step>
### Open your app's notification settings

In [App Store Connect](https://appstoreconnect.apple.com), open **Apps → your app**. In the
sidebar under **General**, click **App information**. Scroll to **General Information** and find
the **App Store Server Notifications** section.

Editing these URLs requires the **Account Holder**, **Admin**, **App Manager**, or **Marketing**
role in App Store Connect.

</Step>

<Step>
### Set the Production Server URL to Version 2

Under **Production Server URL**, click **Set Up URL**, or **Edit** next to an existing URL. Paste
your Voidhash notification URL and choose **Version 2**. Apple offers "Version 1 (deprecated) or
Version 2 notifications". Click **Save**.

</Step>

<Step>
### Set the Sandbox Server URL to Version 2

Under **Sandbox Server URL**, click **Set Up URL**, paste the same Voidhash notification URL,
choose **Version 2**, and click **Save**. Each environment stores its URL and version
independently, so you need to set both.

<Callout type="warn" title="Set both URLs">
If you do not provide a **Sandbox Server URL**, Apple sends notifications for both environments
to the Production URL. If you provide only a Sandbox URL, no notifications are sent in
production. Sandbox changes can take up to about an hour to take effect.
</Callout>
</Step>

</Steps>
