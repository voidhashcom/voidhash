Voidhash ships three client SDKs with the same core workflows — paywalls, purchases,
entitlements, feature flags, and analytics — tailored to each platform. Every SDK talks to the same
project schema, so products, paywalls, and locations configured in Studio work across all of them.

| SDK           | Platforms    | Store integration |
| ------------- | ------------ | ----------------- |
| React Native  | iOS, Android | StoreKit 2 and Google Play Billing through native modules |
| Swift         | iOS          | StoreKit 2        |
| Kotlin        | Android      | Google Play Billing |

<Callout type="info" title="Development purchase mode is React Native-only">
  Debug builds of the React Native SDK can simulate purchases without store setup. Swift and Kotlin
  integrations test against App Store Sandbox or Google Play testing tracks from the start — see
