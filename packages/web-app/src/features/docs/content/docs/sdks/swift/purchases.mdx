Hosted paywalls handle purchases and restores for you. Use the APIs on this page when you build
your own purchase screen and need to load products, start a purchase, or restore earlier ones.

## Load products

`getProducts()` returns the store-backed products configured in your project. Prices come already
formatted for the customer's storefront, so you can render them directly.

```swift
let products = try await voidhash.getProducts()
let monthly = products.first(where: { $0.slug == "monthly" })

if let monthly {
    Text(monthly.displayPrice)
}
```

If a product is missing from the result, the store did not return it. That happens when the product
is not available on the current store account, environment, or provider configuration.

## Start a purchase

`purchase(product:)` buys through StoreKit 2 and syncs the transaction to Voidhash for server
validation. Only after Voidhash accepts the transaction does the SDK finish it with the store. On
success the SDK refreshes the current person, so entitlement grants update without extra work.

```swift
do {
    try await voidhash.purchase(product: monthly)
    dismiss()
} catch let error as VoidhashStoreError where error.code == "USER_CANCELLED" {
    // The customer dismissed the store sheet.
} catch {
    reportError(error)
}
```

Errors surface as `VoidhashStoreError`. Its string form is `"CODE: message"`. Match known codes such
as `USER_CANCELLED` and `PURCHASE_PENDING` when recovery differs. See [Errors](/sdks/swift/errors)
for the full list.

<Callout type="warn" title="Grant access from Voidhash state">
  A successful store dialog is not the entitlement check. Unlock the feature only after the
  refreshed person contains an active grant.
</Callout>

## Restore purchases

Give customers a visible restore action. Restore reconciles every purchase the store still reports
with Voidhash and refreshes the current person. It never creates a second purchase.

```swift
try await voidhash.restorePurchases()
```

## Store sheets

The SDK can also present two StoreKit sheets for you: the code redemption sheet and the manage
subscriptions screen.

```swift
try await voidhash.presentCodeRedemptionSheet()
try await voidhash.showManageSubscriptions()
```

## Common failure cases

- **Product is missing.** Verify the store product mapping in Studio and the Sandbox environment.
- **Purchase already in progress.** Disable repeated taps while a purchase is running.
- **Customer cancels.** Match `USER_CANCELLED` and treat it as an expected result, not an error.
- **Purchase succeeds but access is absent.** Retry the person fetch, and verify in Studio that the
  product grants the expected perk.
- **Restore finds nothing.** Confirm the device uses the same App Store account as the original
  purchase.
